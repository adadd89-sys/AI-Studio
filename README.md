# AI Studio

AI Studio is a multi-agent workspace for planning, building, reviewing, and testing digital products.

## Initial milestone

Build a working project workspace with a Russian-language interface, a task intake flow, and an extensible architecture for AI agents.

## Planned stack

- React + Vite for the web interface
- Cloudflare Workers for the backend (to be added after the UI foundation)
- Cloudflare D1 for persistent project data (to be added)
- Gemini API as the first model integration, subject to free-tier limits
- GitHub for source control

## Current status

Repository initialized. The first milestone is the interface foundation; live agent orchestration and model integrations are not implemented yet.
